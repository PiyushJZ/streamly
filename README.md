# Streamly

## Simplified Multiplatform Streaming

## Project Setup

Clone repo and submodules
```bash
# For cloning the repo
git clone git@github.com:PiyushJZ/streamly.git

# OR

# For cloning the repo and all the submodule repos for ui and server micro-services
git clone --recurse-submodules git@github.com:PiyushJZ/streamly.git
```
